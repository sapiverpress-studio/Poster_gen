Paste this into **AI Title Instructions**:

```text
Write a clear Etsy title for a children's educational poster.

Start with the subject of the artwork, for example Counting, Shapes, Dinosaur Colours, Space or Animal Alphabet.

Use natural UK English and avoid keyword stuffing.

Include relevant phrases such as educational poster, kids wall art, nursery wall art or learning poster only where they read naturally.
```

## SKU / Filename System

PrintShrimp generates the SKU from the filename and requires the resulting SKU to stay within its character limit.

Use short, structured filenames.

### First live batch

```text
SP-EL-001-COUNTING.png
SP-EL-002-SHAPES.png
SP-EL-003-DINO-COLOURS.png
SP-EL-004-SPACE.png
SP-EL-005-ANIMAL-ALPHABET.png
```

### Naming pattern for future batches

```text
SP-EL-###-SHORT-SUBJECT.png
```

Keep the filename readable and short enough to avoid PrintShrimp's SKU-length error.

## Important Notes

- The PrintShrimp Free plan used for this setup provides **5 AI listings per month**, **unlimited manual listings**, and **1 template**.
- The first batch used all 5 monthly AI listing credits.
- The allowance resets each cycle.
- A template is used to create/configure listings. Existing PrintShrimp products/listings should not depend on retaining an old deleted template, but SKU/product mapping should always be checked if changing systems.
- Do not regenerate listings simply because the Etsy handoff temporarily fails. Use PrintShrimp's **Retry listing** function first.
- For future international expansion, create a deliberate, verified fulfilment setup rather than guessing carrier settings.
